# Public Roadmap

This roadmap is intentionally public-safe and does not expose implementation details.

## Ask Intelligence

- Improve understanding across real-world cyber security phrasing.
- Expand product-specific answer coverage.
- Strengthen follow-up handling and thread context.
- Improve source/citation quality for vendor how-to questions.

## Upload Analysis

- Broaden firewall, appliance, and cloud config detection.
- Improve SIEM, EDR, EVTX, email, scanner, and DFIR export summaries.
- Produce stronger timelines, findings, severity, recommendations, and validation steps.

## Reports

- Improve executive summaries.
- Improve IR report exports.
- Add clearer findings and remediation sections.
- Keep source review at the bottom when appropriate.

## Quality

- Expand public-safe question seeds.
- Track misunderstood asks.
- Track low-confidence or generic answers.
- Improve beta feedback review.

## Local Case Kit

- Keep improving local/offline workflows for large cases.
- Make update/download instructions clearer.
- Preserve the protected runtime model.
