# Quality Status

Updated October 9, 2026. This describes tested scope, not universal accuracy or a certification.

## Precision Update

The corrected local product and compiled Local Case Kit reject previously reproduced lab-specific details that were absent from unfamiliar uploads. Routine authorized USB transfers and maintenance are negative controls, not automatic proof of compromise. Findings include bounded observed records and artifact/hash references; incomplete text analysis is disclosed.

Follow-up formatting, file exclusions, stored evidence metadata, local security headers, and first-run credentials have new regression coverage. Excluding the last matching file does not silently bring it back into a report. Larger serialized uploads retain their full bounded context instead of being cut into invalid JSON.

Bracketed filenames remain exact evidence references; control characters and Unicode line separators are rejected. ZIP paths are checked before platform normalization so Windows cannot hide an archive defect that would fail Linux verification.

Acquisition-only summaries no longer recommend containing active access or label a patient zero without supporting compromise evidence. Suspicious execution, persistence, explicit log clearing, or incomplete processing cannot be dismissed merely because a collector is present.

SMB/RDP exposure now binds to enabled native allow rules in supported FTD/Azure JSON, pfSense XML, and PAN-OS set formats, rather than borrowing nearby rule names. Internal-only, deny, disabled, and explicit UDP-only SMB objects are negative controls. Missing pfSense IPS coverage is uncertainty, not proof that protection is disabled. Unsupported configurations still use pattern-based review. Configuration checks are bounded to 12,000 redacted characters; larger exports carry an incomplete-review notice.

A browser-discovered KRBTGT follow-up now honors requests such as "only three short bullets" without repeating the long briefing or training footer. The brief retains the security risk and controlled-reset warning. This specific path is tested; not every constraint or answer route is certified. Loading shows only "Preparing response," without inventing local model usage or timed server stages.
