# Security Policy

Report security concerns privately first.

Email: contact@cybsec-ai.com

Please do not open a public issue for:

- Authentication bypass.
- Sensitive data exposure.
- Admin-token problems.
- Upload handling issues.
- Prompt-injection or safety-boundary bypasses.
- Any issue that could put users, systems, or evidence at risk.

Include enough detail to reproduce the issue safely, but do not include real secrets, customer evidence, raw malware, or exploit payloads.
